# 📊 Sales & Revenue Analysis Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive **Sales & Revenue Analysis Dashboard** built using Power BI.
It provides insights into sales, profit, customer distribution, and product performance across different regions.

---

## 🎯 Objectives

* Analyze overall sales and profit trends
* Identify top-performing countries and products
* Understand customer distribution and sales contribution
* Support data-driven decision making

---

## 📂 Dataset

* Source: Excel dataset
* Contains:

  * Country
  * Sales
  * Profit
  * Customer details
  * Product categories
  * Sales manager data

---

## 📊 Dashboard Features

* KPI Cards:

  * Total Sales (89.2M)
  * Total Profit (49M)
  * Customer Count (90)

* Visualizations:

  * Sales by Country (Bar Chart)
  * Sales by Customer Type (Donut Chart)
  * Sales by Product (Bar Chart)
  * Sales by Sales Manager (Column Chart)
  * Sales Trend by Year & Quarter (Line/Bar Chart)

---

## 🛠️ Tools & Technologies

* Power BI Desktop
* Power Query (Data Cleaning & Transformation)
* DAX (Calculated Measures)
* Microsoft Excel

---

## 🔍 Key Insights

* India shows the highest sales among all countries
* Supermarkets contribute the largest share of revenue
* Certain products dominate overall sales performance
* Sales trends vary across quarters indicating seasonal impact

---

## 🚀 How to Use

1. Download the `.pbix` file
2. Open using Power BI Desktop
3. Interact with visuals and filters

---

## 📎 Project Files
